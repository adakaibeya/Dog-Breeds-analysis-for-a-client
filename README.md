# Dog-Breeds-analysis-for-a-client
Using python to analyze and answer questions for a client who wants to set up a dog adoption center.

## Project Overview
A Python data analysis project that identifies suitable dog breeds based on specific customer requirements using a dataset of 97 dog breeds.

## Objectives
Identify the top dog breeds that are suitable for the following target customers:
- Families with young children
- Disabled individuals looking for emotional support animals
- Individuals looking for service dogs

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Methodology
- Imported and explored the dataset.
- Applied multiple filtering conditions.
- Sorted qualifying breeds by child-friendliness and barking scores.
- Extracted the top five recommendations.

## Business Application
Demonstrates how data analysis can support personalised dog breed recommendations based on customer preferences.

## Skills Demonstrated
- Data exploration
- Data filtering
- Boolean indexing
- Data sorting
- Descriptive statistics
